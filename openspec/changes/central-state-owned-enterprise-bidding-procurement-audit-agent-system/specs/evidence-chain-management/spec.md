# Spec Delta

## Purpose

完整的证据链管理能力，每条审核结论绑定原文锚点、抽取结构、规则依据、置信度等元数据，实现审核过程的可追溯性和审计合规性。

## ADDED Requirements

### Requirement: 完整证据链条构建
系统SHALL为每条审核结论构建完整的证据链条，包括原文锚点、抽取结构、命中的规则ID与版本、判定依据、结论和置信度。

#### Scenario: 客观项证据链
- **WHEN** 规则引擎完成客观项审核
- **THEN** 系统SHALL构建包含以下元素的证据链：
  - 原文锚点：文件ID-章-节-条-款层级信息
  - 抽取结构：标准化后的条款内容
  - 规则依据：命中的规则ID、版本和具体条文
  - 判定过程：规则匹配和计算过程
  - 审核结论：通过/不通过及具体说明
  - 置信度评分：基于规则匹配度的置信度

#### Scenario: 主观项证据链
- **WHEN** LLM完成主观项审核
- **THEN** 系统SHALL构建包含以下元素的证据链：
  - 原文锚点：精确到句子级别的原文位置
  - 抽取结构：上下文相关的条款内容
  - 模型推理：使用的prompt、few-shot样本和模型响应
  - 判定依据：LLM的推理过程和判断理由
  - 审核结论：分级判定结果
  - 置信度评分：模型输出的置信度
  - 不确定性分析：边界情况的说明

### Requirement: 原文锚点无中断原则
系统SHALL严格执行"无原文锚点的结论一律拦截"的硬规则，确保每条审核结论都有可追溯的原文依据。

#### Scenario: 锚点缺失检测
- **WHEN** 审核流程产生结论但未绑定有效原文锚点
- **THEN** 系统SHALL自动拦截该结论，标记为"证据链不完整"，需要人工补全或重新审核

#### Scenario: 锚点有效性验证
- **WHEN** 系统绑定原文锚点
- **THEN** 系统SHALL验证锚点对应的原文内容是否存在且可访问，确保锚点的有效性

#### Scenario: 跨文档锚点处理
- **WHEN** 审核结论需要引用多个文档的内容
- **THEN** 系统SHALL支持复合锚点，包含多个文档的锚点信息，形成完整的引用链

### Requirement: 证据链存储与检索
系统SHALL将证据链以结构化JSON格式存储，支持快速检索和原文定位，无需重新运行整个审核流程。

#### Scenario: 证据链存储
- **WHEN** 审核完成
- **THEN** 系统SHALL将完整的证据链JSON存储在数据库中，与审核结论建立关联

#### Scenario: 快速原文定位
- **WHEN** 专家需要查看某条结论的原文依据
- **THEN** 系统SHALL根据证据链中的锚点信息，直接定位到原文具体位置，无需重新解析文档

#### Scenario: 证据链检索
- **WHEN** 审计人员需要查询特定条款的所有审核历史
- **THEN** 系统SHALL支持按条款内容、规则ID、审核时间等维度检索相关证据链

#### Scenario: 批量证据导出
- **WHEN** 需要导出某次审计的所有证据材料
- **THEN** 系统SHALL支持批量导出证据链和对应的原文快照，生成完整的审计材料包

### Requirement: 证据链版本管理
系统SHALL支持证据链的版本管理，当规则或文档更新时，能重新评估历史结论并生成新的证据链版本。

#### Scenario: 规则更新重评估
- **WHEN** 相关规则发生变更
- **THEN** 系统SHALL支持使用新规则版本重新评估历史结论，生成新的证据链版本，同时保留历史版本

#### Scenario: 文档修正重评估
- **WHEN** 招标文件发布澄清或修正
- **THEN** 系统SHALL支持基于修正后的文档重新审核，生成新的证据链，标记为修正版本

#### Scenario: 版本对比分析
- **WHEN** 同一结论有多个证据链版本
- **THEN** 系统SHALL支持版本对比，展示规则、文档或判断依据的变化情况

### Requirement: 审计可追溯性保障
系统SHALL确保所有审核结论在审计时能秒级回答"当时依据哪条、哪版规则判的"的问题。

#### Scenario: 历史时点回溯
- **WHEN** 审计人员查询某历史时间点的审核依据
- **THEN** 系统SHALL能精确还原该时间点生效的规则版本、使用的few-shot样本和判断逻辑

#### Scenario: 决策过程重现
- **WHEN** 需要复核历史审核决策
- **THEN** 系统SHALL能基于保存的证据链完整重现当时的决策过程，包括所有中间步骤

#### Scenario: 审计报告生成
- **WHEN** 需要生成正式的审计报告
- **THEN** 系统SHALL能自动生成包含完整证据链的审计报告，每条结论都有可验证的原文依据
