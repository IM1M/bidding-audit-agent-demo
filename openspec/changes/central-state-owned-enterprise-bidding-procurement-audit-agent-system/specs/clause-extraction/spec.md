# Spec Delta

## Purpose

从结构化文档中智能抽取采购相关条款，支持多文档类型（招标文件、技术规格书、合同范本等）的可配置模板映射，实现条款的标准化提取和分类。

## ADDED Requirements

### Requirement: 可配置的条款模板映射
系统SHALL支持"文档类型 → 条款模板 → 规则包"的可配置映射关系，新增文档类型时主要配置规则包而不修改核心引擎代码。

#### Scenario: 公开招标文件模板应用
- **WHEN** 系统识别文档类型为"公开招标文件"
- **THEN** 系统SHALL自动加载对应的条款模板和规则包，进行标准化条款抽取

#### Scenario: 邀请招标文件模板应用
- **WHEN** 系统识别文档类型为"邀请招标文件"
- **THEN** 系统SHALL加载特定于邀请招标的条款模板，处理差异化条款

#### Scenario: 模板动态加载
- **WHEN** 管理员上传新的文档类型模板配置
- **THEN** 系统SHALL在不重启的情况下动态加载新模板，立即生效

### Requirement: 条款智能识别与抽取
系统SHALL基于小模型预筛和模板化抽取算法，从文档结构中识别并提取采购相关的标准化条款。

#### Scenario: 资格条件条款抽取
- **WHEN** 文档中包含投标人资格要求相关内容
- **THEN** 系统SHALL识别并提取"投标人资格"条款，包括资质要求、业绩要求、财务要求等子项

#### Scenario: 技术规格条款抽取
- **WHEN** 文档中包含产品技术参数和性能指标
- **THEN** 系统SHALL识别并提取"技术规格"条款，结构化表示参数名称、要求和测试方法

#### Scenario: 商务条款抽取
- **WHEN** 文档中包含价格、付款、交付等商务内容
- **THEN** 系统SHALL识别并提取"商务条款"，包括报价要求、付款方式、交付期限等

#### Scenario: 法律合规条款抽取
- **WHEN** 文档中包含法规引用和合规要求
- **THEN** 系统SHALL识别并提取"法律合规"条款，关联具体法规条文和企业内部制度

### Requirement: 条款分类与标准化
系统SHALL将抽取的条款按标准分类体系进行归类，生成统一的条款数据模型。

#### Scenario: 条款分类映射
- **WHEN** 系统抽取到一条条款文本
- **THEN** 系统SHALL根据预定义的分类体系（如：资格类、技术类、商务类、法律类）进行自动分类

#### Scenario: 条款标准化表示
- **WHEN** 同类条款在不同文档中有不同的表达方式
- **THEN** 系统SHALL将条款内容转换为标准化的数据模型，包括条款类型、关键字段、约束条件和原文锚点

#### Scenario: 跨文档条款去重
- **WHEN** 同一采购包包含多个关联文档
- **THEN** 系统SHALL识别跨文档的重复条款，合并为单一标准化表示，避免冗余审核

### Requirement: 抽取质量与可追溯性
系统SHALL为每个抽取的条款提供质量评分和完整的可追溯信息。

#### Scenario: 抽取置信度评估
- **WHEN** 条款抽取完成
- **THEN** 系统SHALL输出抽取置信度评分，基于模板匹配度、语义一致性和结构完整性

#### Scenario: 原文锚点绑定
- **WHEN** 条款被成功抽取
- **THEN** 系统SHALL绑定完整的原文锚点信息，包括文件ID、章节位置和具体坐标

#### Scenario: 抽取失败处理
- **WHEN** 条款抽取置信度低于阈值（如<80%）
- **THEN** 系统SHALL标记该条款为需要人工校验，并提供候选抽取结果和原文位置供专家复核
