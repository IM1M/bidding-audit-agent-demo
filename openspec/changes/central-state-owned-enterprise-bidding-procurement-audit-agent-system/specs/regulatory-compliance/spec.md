# Spec Delta

## Purpose

满足企业等保三级、国密算法、信创适配等合规要求的系统能力，确保系统在安全、可靠、可信的环境中运行，符合国家网络安全和信息化要求。

## ADDED Requirements

### Requirement: 全栈信创环境适配
系统SHALL支持在国产化信创环境中部署和运行，包括CPU、操作系统、数据库、中间件等全栈适配。

#### Scenario: CPU架构适配
- **WHEN** 系统部署在海光或鲲鹏CPU架构上
- **THEN** 系统SHALL提供arm64多架构镜像，确保在国产CPU上的兼容性和性能

#### Scenario: 操作系统适配
- **WHEN** 系统部署在银河麒麟或openEuler操作系统上
- **THEN** 系统SHALL验证所有二进制依赖（OCR、onnxruntime、numpy等）在ARM架构上的兼容性和性能

#### Scenario: 数据库适配
- **WHEN** 系统使用国产数据库（金仓、达梦、openGauss）
- **THEN** 系统SHALL提供对应的数据库驱动和适配层，确保向量检索功能的正常使用

#### Scenario: 中间件适配
- **WHEN** 系统需要国产中间件（东方通、宝兰德）
- **THEN** 系统SHALL提供相应的配置和适配方案，确保消息队列、缓存等功能的正常运行

### Requirement: 数据安全与隐私保护
系统SHALL实现"数据不出域"的完全私有化部署，对敏感数据进行脱敏处理，符合等保三级的数据安全要求。

#### Scenario: 数据边界清单管理
- **WHEN** 系统处理招标文件和相关数据
- **THEN** 系统SHALL明确"数据不出域"的边界清单，包括原始文件、条款向量、专家修正样本、Trace日志、模型权重等全部留在客户内网

#### Scenario: 外部API调用管控
- **WHEN** 系统需要调用外部模型API
- **THEN** 系统SHALL要求显式审批并且对调用数据进行脱敏处理，防止敏感信息泄露

#### Scenario: 数据脱敏处理
- **WHEN** 系统记录操作日志或生成报告
- **THEN** 系统SHALL对敏感信息（如供应商信息、金额等）进行脱敏处理，符合隐私保护要求

#### Scenario: 数据加密存储
- **WHEN** 系统存储招标文件和审核结果
- **THEN** 系统SHALL支持数据加密存储，包括传输加密和静态加密，确保数据安全

### Requirement: 等保三级合规性
系统SHALL满足网络安全等级保护三级要求，包括身份认证、访问控制、安全审计、入侵防范等方面。

#### Scenario: 身份认证与访问控制
- **WHEN** 用户访问系统
- **THEN** 系统SHALL对接企业统一身份认证，支持OAuth2、SAML、CAS、LDAP协议，实现单点登录和角色权限控制

#### Scenario: 安全审计日志
- **WHEN** 系统进行任何操作
- **THEN** 系统SHALL记录完整的审计日志，包括操作时间、操作人、操作内容和结果，日志留存不少于180天

#### Scenario: 入侵防范与监测
- **WHEN** 系统运行时
- **THEN** 系统SHALL具备入侵检测和防范能力，监控异常访问行为，及时告警和处理安全事件

#### Scenario: 漏洞管理与修复
- **WHEN** 发现系统安全漏洞
- **THEN** 系统SHALL建立漏洞管理流程，及时修复漏洞并验证修复效果

### Requirement: 国密算法与电子签章
系统SHALL支持国密算法（SM2/SM3/SM4）和电子签章集成，满足商用密码应用安全性评估（密评）要求。

#### Scenario: 国密算法支持
- **WHEN** 系统进行数据传输或存储加密
- **THEN** 系统SHALL支持国密算法SM2（非对称加密）、SM3（哈希算法）、SM4（对称加密）

#### Scenario: 电子签章集成
- **WHEN** 系统生成审核报告作为正式交付物
- **THEN** 系统SHALL集成客户既有签章平台或自建CA，支持报告电子签章确认

#### Scenario: 密评自查
- **WHEN** 系统准备进行商用密码应用安全性评估
- **THEN** 系统SHALL提供密评自查工具，检查国密算法应用是否符合要求

### Requirement: 安全可靠测评适配
系统SHALL支持芯片、操作系统、数据库的安全可靠测评要求，确保系统在信创环境中的稳定运行。

#### Scenario: 芯片适配验证
- **WHEN** 系统部署在国产芯片上
- **THEN** 系统SHALL进行芯片适配验证，确保AI推理、OCR处理等计算密集型任务性能达标

#### Scenario: 操作系统兼容性
- **WHEN** 系统在不同国产操作系统上运行
- **THEN** 系统SHALL验证系统依赖库、驱动程序和运行时的兼容性，提供问题解决方案

#### Scenario: 数据库性能验证
- **WHEN** 系统使用国产数据库进行向量检索
- **THEN** 系统SHALL验证向量索引性能、查询响应时间和并发处理能力，确保满足生产要求

#### Scenario: 信创产品兼容性认证
- **WHEN** 系统需要获得信创产品兼容性认证
- **THEN** 系统SHALL提供完整的适配文档和测试报告，支持认证流程
