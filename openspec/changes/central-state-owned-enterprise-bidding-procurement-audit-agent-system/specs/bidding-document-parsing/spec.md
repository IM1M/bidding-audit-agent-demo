# Spec Delta

## Purpose

支持招标文档的OCR解析、版面分析和结构化重建，能还原招标文件中章-节-条-款四级结构树，为后续条款抽取和审核提供准确的原文定位能力。

## ADDED Requirements

### Requirement: 支持多格式文档解析
系统SHALL支持PDF扫描件、Word文档、图片格式等常见招标文件格式的解析，针对扫描件比例高的历史文件提供OCR兜底解析链路。

#### Scenario: PDF扫描件解析
- **WHEN** 系统收到一份PDF格式的招标文件扫描件
- **THEN** 系统SHALL使用PaddleOCR进行文字检测和识别，输出结构化文本和坐标信息

#### Scenario: Word文档解析
- **WHEN** 系统收到一份DOCX格式的招标文件
- **THEN** 系统SHALL直接提取文本内容和格式信息，保留原始文档结构

#### Scenario: 复杂表格处理
- **WHEN** 招标文件中包含跨页的复杂表格
- **THEN** 系统SHALL识别表格结构，重建单元格关系和内容连续性

### Requirement: 还原文档层级结构
系统SHALL通过版面分析算法，将文档内容重建为"章—节—条—款"四级结构树，每级结构SHALL包含标题、内容、页码和坐标信息。

#### Scenario: 四级结构重建
- **WHEN** 系统完成文档解析
- **THEN** 系统SHALL输出包含章、节、条、款四级节点的结构化文档树，每个节点SHALL包含标题文本、起始页码、结束页码和边界坐标

#### Scenario: 标题层级识别
- **WHEN** 文档包含不同字体、字号的标题
- **THEN** 系统SHALL根据字体特征、缩进级别和编号模式识别标题层级关系

#### Scenario: 无标题结构处理
- **WHEN** 文档部分内容缺乏明确的标题标记
- **THEN** 系统SHALL基于内容语义和上下文关系推断合理的结构划分

### Requirement: 原文锚点定位
系统SHALL为文档中的每个文本片段生成唯一的原文锚点标识符，支持精确到句子级别的原文位置回溯。

#### Scenario: 锚点生成
- **WHEN** 系统完成结构重建
- **THEN** 系统SHALL为每个条款生成唯一锚点标识符，格式为：文件ID-章-节-条-款-句子序号

#### Scenario: 锚点解析
- **WHEN** 系统收到一个原文锚点标识符
- **THEN** 系统SHALL能定位到对应的文档位置，返回该位置的文本内容和坐标信息

#### Scenario: 跨页内容锚点
- **WHEN** 条款内容跨越多页
- **THEN** 系统SHALL生成包含起始页和结束页的复合锚点，能完整定位整个条款

### Requirement: 文档解析质量保证
系统SHALL提供文档解析质量的评估指标，支持解析失败的重试机制和人工校验兜底。

#### Scenario: 解析质量评估
- **WHEN** 文档解析完成
- **THEN** 系统SHALL输出解析置信度评分，基于文字识别准确率、结构完整性和一致性进行评估

#### Scenario: 低质量解析重试
- **WHEN** 解析置信度低于预设阈值（如<85%）
- **THEN** 系统SHALL自动触发重试流程，尝试不同的解析参数或算法

#### Scenario: 人工校验触发
- **WHEN** 重试后解析质量仍不达标
- **THEN** 系统SHALL将文档标记为需要人工校验，并通知专家进行手动处理
